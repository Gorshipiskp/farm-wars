# server/010 + client/002 — NIKITA: дорожная карта сервера и клиента

**Статус:** `PLANNED`  
**Владелец:** `NIKITA` (зоны `server/`, `client/`, `db/`, `tools/*` кроме smoke под SANYA)  
**Зависимости:** движок SANYA для новых engine-action; контракты v1

---

## Контекст

Сервер + клиент закрывают **играбельный MP-срез**:

- матч 2–4, join, tick loop, каталог из SQLite
- магазин (семена + мука/корм), продажа урожая, животные, саботаж
- UI: ферма, вкладки соперников, боковая панель (урожай / семена / рецепты)
- автотесты MP, vertical slice, server flow

Движок и обогащение **семян** готовы. Дальше — **закрытие MVP по ТЗ продукта**, контрмеры, polish, одиночный режим, контент.
