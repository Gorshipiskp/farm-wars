# Context

ТЗ `engine_cpp/003.SANYA` вводит рост растений и harvest в движке.  
Движок **не читает SQLite** — параметры растения должны приходить в payload с сервера (как `initial_water_level` в `server/002`).

# Goal

Расширить `server/action_enricher.py` для `PLACE_ON_TILE` и `START_RECIPE`, чтобы C++ получал все нужные поля из `GameContentCatalog`.

# Scope

## `PLACE_ON_TILE` — дополнительные поля

Из `catalog.plants[plant_id]`:

- `growth_time_sec`
- `water_decay_per_tick`

Уже есть: `initial_health`, `initial_water_level`.

## `START_RECIPE` — дополнительное поле

- `output_product_id` из `catalog.recipes[recipe_id]`

## После приёмки `SANYA` CP2

- Убрать immediate `HARVEST_PLANT` из `match.enqueue_action` → только очередь тика.

## После приёмки `SANYA` CP3

- Удалить или отключить `Match._advance_factories` — завод в движке.
