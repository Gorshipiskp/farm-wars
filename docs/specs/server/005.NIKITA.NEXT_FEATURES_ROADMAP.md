# Context

`engine_cpp/001–003` (SANYA) завершены. Движок обрабатывает полный цикл: посадка → рост → полив → сбор → завод → победа.

Дальнейшие фичи требуют изменений на стороне NIKITA (клиент + сервер).

# Текущий статус (что уже есть)

| Компонент | Готовность |
|---|---|
| C++ движок | 4 действия + пассивная симуляция + очередь завода |
| Клиент | Lobby + карта + 3 кнопки (W/A/S/D для полива/посадки/рецепта) |
| Сервер | HTTP API + тик-луп + enricher + магазин (BUY_PRODUCT) |
| БД | Schema + seed (3 растения, 1 животное, 2 рецепта, события, саботажи) |

# Что блокирует дальнейшую разработку SANYA

Для каждой новой механики нужны три вещи от NIKITA:
1. **Кнопка в клиенте** — игрок должен иметь возможность выполнить действие
2. **Обработчик на сервере** — принять действие, обогатить, отправить в движок (или обработать server-side)
3. **Enricher** — добавить данные из БД в payload перед движком

# Задачи для NIKITA (в порядке приоритета)

## 1. Завод: обогащение очереди (HIGH, 15 мин)

Сейчас при завершении рецепта движок авто-запускает следующий из `queue`.
Но `QueueItem` не содержит `duration_sec` — движок использует default 30s.

**Нужно:** в `server/action_enricher.py` при добавлении рецепта в очередь
сохранять `duration_sec` из `recipes.production_time_sec`.

Либо добавить `"QUEUE_RECIPE"` как новый action_type, который сервер обрабатывает
(проверяет factory_type, списывает ингредиенты, добавляет в очередь с duration).

## 2. Случайные события (HIGH, требует engine_cpp/004)

**Клиент:** не требует изменений (события применяются сервером)

**Сервер:**
- Раз в N тиков (например, каждые 30) с вероятностью 20% выбрать случайное событие из БД
- Сформировать action для движка или применить server-side
- Оповестить клиентов через события

**Движок (SANYA, engine_cpp/004):**
- `APPLY_EVENT` action: применить эффект события ко всем клеткам
  - DROUGHT: water_level всех клеток -20
  - FLOOD: water_level всех клеток +30
  - EARTHQUAKE: health всех растений -30
  - EPIDEMIC: health всех животных -40

## 3. Животные (MEDIUM)

**БД:** уже есть (`animals`, `cow`, `feed`)

**Клиент:** кнопка "Купить корову" (BUY_ANIMAL), кнопка "Покормить" (FEED_ANIMAL)

**Сервер:**
- BUY_ANIMAL: списать Бестики, добавить корову на ANIMAL-клетку
- FEED_ANIMAL: проверить наличие корма в инвентаре, списать, обогатить

**Движок (SANYA, engine_cpp/005):**
- FEED_ANIMAL: покормить животное, сбросить таймер голода
- Пассивная фаза для животных: счетчик продукции (молоко)

## 4. PvP саботаж (LOW)

После того как заработают животные и события — добавить кнопки саботажа
и контрмер в клиент, обработчики на сервер, логику в движок.
