# Context

PvP sabotage from DB seed; engine not required for MVP.

# Goal

`APPLY_SABOTAGE` — server immediate action targeting opponent tile.

# Effects

| sabotage_id | effect |
|-------------|--------|
| `poison_water` | `water_level -= 30` |
| `spread_disease` | PLANT `health -= 40` or kill |
| `mine_tile` | flag `MINED`, PLANT `-25` health |

# Events

- `SABOTAGE_APPLIED` — `is_hidden` from DB; client hides toast from victim when hidden
- `SABOTAGE_FAILED` — money, own tile, unknown
