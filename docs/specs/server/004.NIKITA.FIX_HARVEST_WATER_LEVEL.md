# Context

`engine_cpp/003` Phase 1 зафиксировал: `water_level` — свойство грядки (TileState), не растения.
После сбора урожая или смерти растения влажность почвы должна оставаться неизменной.

Сейчас `server/harvest.py` обнуляет `water_level` при сборе:
```python
tile["water_level"] = None  # ← баг: вода исчезает
```

При повторной посадке на ту же грядку влажность = 0, прогресс-бар пустой, растение не растет пока игрок не польет.

# Goal

Исправить: `HARVEST_PLANT` не должен менять `water_level` грядки.

# Scope

**In scope:**
- Убрать `tile["water_level"] = None` из `server/harvest.py:_process_harvest_plant`.
- Проверить `server/world_factory.py` — `water_level` на пустых клетках должен быть числом, не null.

**Out of scope:**
- Клиентский прогресс-бар (отдельный баг в `client/`).
- Обогащение `PLACE_ON_TILE` (уже работает через `server/002`).

# Functional Requirements

1. После сбора урожая `water_level` клетки сохраняет текущее значение.
2. После смерти растения `water_level` сохраняется (движок уже не обнуляет).
3. Пустые грядки (`occupant_type = "EMPTY"`) должны иметь `water_level` как число (не null).

# Implementation Plan

1. В `server/harvest.py`: убрать строку `tile["water_level"] = None`.
2. В `server/world_factory.py`: убедиться что `water_level` задается числом для пустых клеток.
3. Проверить `py tools/test_server_flow.py` после исправления.

# Checkpoints

1. **Fix Applied** — `tile["water_level"] = None` убран.
2. **Test Pass** — `test_server_flow.py` проходит.

# Acceptance Criteria

- После `HARVEST_PLANT` → `water_level` не меняется.
- После повторной посадки на ту же грядку → `water_level` тот же что был.
- `test_server_flow.py` зеленый.
