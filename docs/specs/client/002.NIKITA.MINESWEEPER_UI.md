# Context

SANYA написал модуль `minesweeper/` — чистую игровую логику «Сапера» без UI.
Игра нужна для PvP-механики: когда игрок находит мину на ферме,
открывается всплывающее окно с сапером. Разминировал → мина убрана.
Подорвался → поле перегенерируется, играешь до победы.

# Goal

Прикрутить pygame-окно сапера к клиенту Farm Wars.

# Что уже сделано (SANYA)

Файлы: `minesweeper/__init__.py`, `minesweeper/game.py`

Класс `Minesweeper` — вся логика:

| Метод | Описание |
|---|---|
| `Minesweeper(w, h, mines)` | Создать поле (мины расставляются после первого клика) |
| `click(x, y) -> ClickResult` | Открыть клетку. Возвращает `SAFE`, `WIN`, `LOST` |
| `toggle_flag(x, y)` | Поставить/убрать флажок |
| `get_board() -> list[list[dict]]` | Поле для отрисовки |
| `is_won()`, `is_lost()` | Статус игры |
| `reset()` | Новая игра |
| `get_flagged_count() -> int` | Счетчик флажков |
| `Minesweeper.preset("easy"/"medium"/"hard")` | Пресеты сложности |

Формат клетки из `get_board()`:
```python
{
    "is_mine": bool,         # true только после проигрыша
    "is_revealed": bool,
    "is_flagged": bool,
    "adjacent_mines": int,   # 0-8, только у открытых клеток
    "is_exploded": bool,     # клетка с миной, на которую нажали
}
```

Тесты: `py tools/test_minesweeper.py` (12 тестов, все PASS).

# Что нужно сделать NIKITA

## 1. Всплывающее окно сапера

При клике на заминированную клетку фермы (где `"MINED"` во `flags`) —
открыть pygame-окно (или Surface поверх основного) с полем сапера.

- Окно должно блокировать основной игровой цикл (игрок не может управлять фермой пока не закроет сапера)
- Размер окна подбирается под размер поля (9×9, 12×12, 15×15)

## 2. Отрисовка поля

Для каждой клетки из `get_board()`:
- **Закрытая**: серый квадрат с рамкой
- **Флажок**: красный треугольник/флаг на сером фоне
- **Открытая пустая** (adjacent_mines=0): светлый квадрат
- **Открытая с цифрой**: число цветом (1=синий, 2=зеленый, 3=красный, 4+=темно-синий)
- **Мина** (после проигрыша): черный круг / бомба
- **Взорванная** (is_exploded): красный фон с миной

Сверху — счетчик флажков: `🏴 M/N` (где M — поставлено, N — всего мин)

## 3. Управление

- **Левый клик** → `minesweeper.click(x, y)`
  - Если `LOST` → показать все мины на 1.5 секунды, потом `minesweeper.reset()`
  - Если `WIN` → закрыть окно, убрать мину с клетки фермы
- **Правый клик** → `minesweeper.toggle_flag(x, y)`
- **Клавиша R** → `minesweeper.reset()`
- **Клавиша ESC** → закрыть окно без разминирования

## 4. Связь с фермой

При победе в сапере:
- Убрать `"MINED"` из `tile.flags` (отправить action на сервер, или сервер сам обработает)
- Закрыть окно сапера
- Показать Toast: «Мина обезврежена!»

## 5. Определение позиции клетки по координатам мыши

```python
cell_size = window_width // minesweeper.width
x = mouse_x // cell_size
y = mouse_y // cell_size
```
