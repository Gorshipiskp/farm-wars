# client/002 — Web-клиент: Svelte + TypeScript + Vite (без SvelteKit)

**Статус:** `IN_PROGRESS`  
**Владелец:** `NIKITA`  
**Зависимости:** `server/001`, `GAME_CONTRACTS_V1.md`, pygame-клиент (`client/001`) — reference до parity

---

## Цель

Заменить pygame-клиент на браузерный: **Vite + Svelte (SPA) + TypeScript**.  
Сервер, движок (SANYA), БД и контракты **не меняем** — только способ отображения и ввода.

pygame остаётся в репозитории до **feature parity**, затем помечаем deprecated.

---

## Принципы миграции

1. **Contract-first** — типы и API 1:1 с `GAME_CONTRACTS_V1` и `client/net.py`.
2. **Тонкий клиент** — без игровой логики; только UI + `fetch` + poll sync.
3. **Поэкранная parity** — лобби → матч → победа; после каждого экрана — ручная проверка + тест.
4. **Dev UX** — Vite proxy на `/api` → `localhost:8765`; LAN — прямой URL + CORS на сервере.

## Серверные изменения (минимум)

| Изменение | Файл | Зачем |
|-----------|------|--------|
| CORS `Access-Control-*` | `server/http_api.py` | LAN: UI на :5173, API на :8765 |
| (опц.) StaticFiles `/` | `server/http_api.py` или `main.py` | один порт в проде |
| (опц.) `GET /api/config` | — | только если понадобится default host |

Движок и match logic **не трогаем**.

## Dev-команды

```bash
# терминал 1
py tools/init_db.py --seed
py -m server

# терминал 2
cd web
npm install
npm run dev
# → http://localhost:5173  (API через proxy /api)
```
