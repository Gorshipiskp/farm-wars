# Context

SANYA написал модуль `waterflow/` — чистую игровую логику мини-игры «три в ряд с вёдрами» без UI.
Игра нужна для разминирования саботажа воды (`WATER_SABOTAGE`).

# Goal

Прикрутить pygame-окно «три в ряд» к клиенту Farm Wars.

# Что уже сделано (SANYA)

Файлы: `waterflow/__init__.py`, `waterflow/game.py`

Класс `WaterFlow`:

| Метод | Описание |
|---|---|
| `WaterFlow(w, h, tile_types)` | Создать поле (8×8, 5 цветов) |
| `swap(x1, y1, x2, y2) -> SwapResult` | Поменять два соседних тайла. Результат: `INVALID`, `NO_MATCH`, `MATCHED`, `WIN`, `LOST` |
| `get_grid() -> list[list]` | Поле для отрисовки. `'B'` = ведро, `1..5` = цветной тайл, `None` = пусто |
| `is_won()`, `is_lost()` | Статус игры |
| `reset()` | Новая игра |
| `get_delivered_count()` | Сколько вёдер доставлено |

Правила игры:
- Сверху ряд вёдер. Ниже — цветные тайлы (5 цветов).
- Игрок свайпает соседние тайлы чтобы составить 3+ в ряд.
- 3+ в ряд → тайлы исчезают → всё падает вниз → новые тайлы сверху.
- Вёдра только падают, их нельзя двигать/объединять.
- Ведро достигло низа → доставлено (исчезает).
- Доставил все вёдра → победа.
- Нет ходов → перемешивание. После перемешивания всё ещё нет → поражение → рестарт.

Тесты: `py tools/test_waterflow.py` (10 тестов, все PASS).

# Что нужно сделать NIKITA

## 1. Всплывающее окно

При обнаружении саботажа воды — открыть pygame-окно с полем 8×8.
Окно блокирует ферму до победы/закрытия.

## 2. Отрисовка поля

Для каждой клетки из `get_grid()`:
- **Пусто (`None`)**: не отрисовывать (или темный квадрат на время анимации)
- **Ведро (`'B'`)**: синий квадрат с иконкой ведра
- **Тайлы 1–5**: цветные квадраты (5 разных цветов)
- Выделение: подсветить выбранный тайл

Сверху: счетчик «Вёдра: N/M» (доставлено / всего)

## 3. Управление

- **Клик по тайлу** → выбрать (подсветить)
- **Клик по соседнему** → `wf.swap(x1, y1, x2, y2)`
  - `INVALID` → сбросить выбор
  - `NO_MATCH` → анимация «неудачного свапа» (тайлы меняются и возвращаются обратно)
  - `MATCHED` → анимация: совпавшие исчезают, остальные падают, новые сверху
  - `WIN` → показать «Победа!», закрыть окно, убрать саботаж с воды
  - `LOST` → показать «Неудача», авто-рестарт
- **Свайп (drag)** → то же что два клика
- **R** → `wf.reset()`
- **ESC** → закрыть без эффекта

## 4. Анимации (для NIKITA)

- **Свап**: тайлы плавно меняются местами (0.2с)
- **Неудачный свап**: тайлы меняются и возвращаются (0.3с)
- **Исчезновение**: совпавшие тайлы мигают и исчезают (0.3с)
- **Падение**: тайлы плавно съезжают вниз (0.15с на клетку)
- **Новые тайлы**: появляются сверху с небольшим отскоком

## 5. Связь с фермой

При победе:
- Убрать эффект `WATER_SABOTAGE` с воды
- Закрыть окно
- Показать Toast: «Вода очищена!»
