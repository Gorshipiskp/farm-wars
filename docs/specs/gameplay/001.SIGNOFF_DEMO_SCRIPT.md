
## Демо: 2 игрока → победа (bread)

1. `py tools/init_db.py --seed`
2. `py -m server` — записать join code и LAN IP
3. **Клиент 1 (хост):** Проверить связь → Создать → Начать
4. **Клиент 2:** IP хоста → Войти по коду → дождаться старта (не залипать в лобби)
5. Оба видят свою ферму; клик по **чужой** ферме (снизу) — саботаж
6. **Esc** — выход в меню без «возврата» в старый матч
7. **p1:** магазин → посадка → полив → сбор → мука → печь хлеб
8. Победа: overlay «Победа» у p1; у p2 — тот же финал после sync

## Демо: 3 игрока (опционально)

1. Хост Create; два гостя Join по одному коду
2. Хост Start — оба гостя автоматически в матче
3. p2 саботирует p1, p3 саботирует p2 (клик по чужой ферме + X)
4. Автопроверка: `py tools/test_multiplayer.py`

## Демо: торт (опционально)

```bat
set FARM_WARS_WIN_PRODUCT=cake
py -m server
```

Нужно: корова → корм → молоко → рецепт торта.
