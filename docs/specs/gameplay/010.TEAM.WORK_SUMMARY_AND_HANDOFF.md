## 1. Что реализовано (кратко)

### Игровой цикл

- Посадка → полив → рост → сбор → крафт на заводах → продажа → победа по целевому продукту.
- **Семена и урожай разделены:** в инвентаре `*_seed` (посадка, магазин), культуры `wheat`, `corn`, … (сбор, рецепты, продажа).
- Сервер обогащает `PLACE_ON_TILE` полями `seed_product_id`, `crop_product_id`; движок списывает семена.

### Контент (MVP+)

- 6 культур, 4 животных, 8 рецептов, 3 завода на игрока (BAKERY / DAIRY / MEAT).
- Ферма: 6 грядок + 2 загона, сетка 4×2, `water_decay_per_tick = 0` в seed.
- Случайные события (DROUGHT, RAIN, EARTHQUAKE, EPIDEMIC), PvP-саботаж (3 типа из БД).

### Мультиплеер 2–4

- Join по коду, отдельные фермы на карте, sync по HTTP.
- Вкладки соперников в UI, roster в лобби (`GET /api/matches/{id}/roster`).
- Автотест: `tools/test_multiplayer.py`.
- Проверка владельца клетки: `WATER_PLANT`, `HARVEST`, `PLACE`, `FEED` (см. `server/009`).

### Клиент (pygame)

- Лобби + матч 1280×800, боковая панель «Ферма и склад»: урожай / семена / магазин / рецепты / животные.
- Горячие клавиши: W T H B C F V X, 1–6 — выбор семян.
- Исправления: `_viewed_opponent_tiles`, `_send_buy_animal`, фильтр чужих ошибок в тостах.

### Сервер

- HTTP API, tick loop, immediate shop/sell/animals/sabotage.
- `shop.py`: покупка только семян + `flour` / `feed`.
- `sell.py`: только `RAW` / `PROCESSED`.

### Движок

- C++ `engine_core` + зеркальный `engine_core_stub`.
- Сборка: `py tools/build_engine.py` (после остановки server/client на Windows).

### Документация и тесты

- Контракты: `docs/contracts/GAME_CONTRACTS_V1.md` (семена, магазин, продажа).
- `tools/smoke_test.py`, `test_server_flow.py`, `test_vertical_slice.py`, `test_db_pricing.py`, `verify_seed.py`.

## 4. Известные ограничения MVP

- Нет WebSocket — только HTTP poll sync.
- `CONTRACT_ERROR` из движка **без `player_id`** — в MP сложнее понять, кто ошибся (см. ТЗ SANYA/NIKITA).
- `START_RECIPE` на чужой завод не отклоняется в C++ (backlog).
- Контрмеры в БД есть, **игровой обработчик не подключён**.
- Ручной LAN 3–4 клиента для `gameplay/009` — ещё на sign-off.
- После смены `engine_cpp` обязательна пересборка `.pyd` и `init_db --seed`.
