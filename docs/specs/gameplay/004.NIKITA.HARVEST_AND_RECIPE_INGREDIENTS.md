# Context

После `gameplay/003` работает: магазин → посадка → полив → печь → победа.

Пробелы для настоящего farm-sim цикла:

| Проблема | Сейчас |
|----------|--------|
| Урожай | Посадил — на грядке «висит» вечно, сырьё не возвращается в инвентарь |
| Рецепт | `bread` запускается без муки и пшеницы в инвентаре |
| Экономика | Нельзя купить муку для пекарни |

# Goal

Замкнуть цикл из `GAME_TECH_REQUIREMENTS.md`:

**купить → посадить → полить → собрать урожай → (докупить муку) → испечь с ингредиентами → победить**.

Зона: `NIKITA` (server + client + контракты). Движок `SANYA` не меняем — `HARVEST_PLANT` server-only.

# Scope

## In scope

- `HARVEST_PLANT` на сервере (как `BUY_PRODUCT`): с грядки в инвентарь, очистка клетки.
- Условие сбора MVP: клетка `PLANT`, `water_level >= 50`.
- Урожай: `+2` единицы `plants.product_id` за сбор.
- `START_RECIPE`: проверка и списание `recipe_ingredients` из SQLite до движка.
- Клиент: клавиша `H`, магазин +`flour`, HUD — состав рецепта `bread`.
- Контракты, тесты, `TASK_STATUS`.

## Out of scope

- Рост по тикам, увядание, животные — отдельные ТЗ.
- `SELL_PRODUCT`, PvP, случайные события.

# Functional Requirements

## FR-1: `HARVEST_PLANT`

- Payload: `{ "tile_id": string }`.
- Сервер (immediate): владелец, `occupant_type == PLANT`, `water_level >= 50`.
- Урожай: `+2` продукта по `catalog.plants[occupant_id].product_id`.
- Клетка → `EMPTY`, событие `PLANT_HARVESTED`.
- Ошибки: `HARVEST_FAILED` (`NOT_READY`, `EMPTY_TILE`, `NOT_OWNER`, …).

## FR-2: Ингредиенты рецепта

- При enrich `START_RECIPE`: проверить инвентарь по `recipe_ingredients`.
- Не хватает → `RECIPE_REJECTED` `NOT_ENOUGH_INGREDIENTS`.
- Иначе списать и передать в движок с `duration_sec`.

## FR-3: Клиент

- `H` — сбор на выбранной клетке.
- Магазин: `Buy flour (8)`.
- HUD: `bread: flour×2, wheat×1`.

# Checkpoints

1. Server harvest + ingredients — тесты.
2. Client H + flour + HUD.
3. Ручной цикл до `bread` без читов.
