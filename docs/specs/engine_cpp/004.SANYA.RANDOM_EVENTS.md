# Scope

- `APPLY_EVENT` в stub и C++
- `DROUGHT`, `RAIN` (`FLOOD` — alias), `EARTHQUAKE`, `EPIDEMIC` (заглушка для животных)
- Тесты 10a–10e в `tools/smoke_test.py`

Out of scope:

# Mechanics

| event_type | Effect |
|------------|--------|
| `DROUGHT` | `water_decay_per_tick` × 1.5 на PLANT-клетках |
| `RAIN` / `FLOOD` | отрицательный decay → вода растёт каждый тик (cap 100) |
| `EARTHQUAKE` | `remaining_time_sec` × 1.5 на активных заводах |
| `EPIDEMIC` | заглушка до животных |
